# 规则文件写法

YAML（也接受 `.json`）。解析器是内置的 YAML 子集实现——沙箱装不了 PyYAML。

## 完整示例

```yaml
name: 库存与新单哨兵
webhook: https://qyapi.weixin.qq.com/cgi-bin/webhook/send?key=xxx   # 可选，也可用环境变量
state: ~/.jdy/watch-state.json      # 可选，去重状态存哪；不写则自动找可写目录

rules:
  - name: 库存告警                   # 必填，且**不能重名**（去重状态按名字存）
    app: 进销存                      # 应用名或 ID
    entry: 库存                      # 表单名或 ID
    when: 库存数量:lt:10             # 阈值型：筛选条件，写法同 jdy-query 的 --where
    message: "{产品名称} 只剩 {库存数量}，低于安全库存"
    remind_after_hours: 24           # 可选：多久后可以就同一条记录再提醒一次
    limit: 500                       # 可选：最多扫多少行

  - name: 新订单提醒
    app: CRM
    entry: 销售订单
    new_rows: true                   # 新增型：只报没见过的记录
    message: "新订单：{客户名称}　{订单总额} 元"
```

## `when`：阈值型的筛选条件

写法和 `jdy-query` / `jdy-excel-bridge` 的 `--where` 完全一样（同一份实现）：

```
字段=值                       # eq
字段:method:值                # 指定比较方式
字段A=甲;字段B:gt:100         # 多条用 ; 连接，关系为 and
```

method 可用 `eq ne in nin range like gt lt empty not_empty verified unverified all`。
字段可以写**显示名**，也可以写字段标识。

⚠️ **认不出的字段会报错，不会静默放行。** 简道云对不认识的字段既不报错也不过滤，
直接返回全表——那样哨兵就变成"每轮把整表都报一遍"。

⚠️ **系统字段筛不了**：`_id`／`createTime`／`updateTime`／`updater` 进 filter
会被接口**静默忽略**（照常 200、返回整表）。所以"最近一小时新增的"这种条件
写不出来，用 `new_rows: true` 让哨兵自己比对。

## `new_rows`：新增型

只报状态里没见过的 `_id`。适合新订单、新线索、新工单。

**第一次跑只建基准、不提醒**——第一次没有基准，把整表当成"新增"推出去，
一张两千行的表就是一条两千行的消息。

## `message`：消息模板

`{字段显示名}` 会被替换成这一行的值：

```yaml
message: "{客户名称} 的订单 {订单编号} 金额 {订单总额}"
```

不写 `message` 就只报记录 ID——能用，但群里没人看得懂，建议都写。

认不出的字段名会**原样留在消息里**（比如 `{不存在的字段}`），不会变成空白：
空白看着像"这个字段是空的"，而实际是模板写错了名字，两件事得能区分。

**想清楚哪些字段适合进群**：群成员往往多于这条数据的相关人。

## `remind_after_hours`：重复提醒

不写：同一条记录**只提醒一次**，除非它先不再命中、之后又命中。
写了：过了这么多小时可以再提醒一次。

选值建议：库存这种"一直存在的问题"设 24（每天提醒一次）；
新单提醒本来就不会重复，不用设。

## 去重状态

不指定时按顺序找第一个能写的：`$JDY_HOME` → `~/.jdy` → 宿主配置目录 → 会话工作目录
→ 临时目录。**后两个跨不了轮次**（下一轮找不回来，会重报），命中时会打印提示。
各端沙箱的写白名单不一样，所以这里不能写死一个路径。文件形如：

```json
{"rules": {"库存告警": {"6a8d7b93…": "2026-08-31T09:00:00+00:00"}}}
```

- 阈值型的记录不再命中就会被**忘掉**——否则它下次再出问题会被当成"已经提醒过"。
- 状态写不进去时（沙箱只读）退化成**每次都提醒**：重复是噪音，漏掉是事故。
- 换机器跑要把这个文件带上，否则新增型规则会重新建基准（那一轮不提醒）。

## 一条规则挂了会怎样

其余规则照跑，挂掉的那条**单独报出来**并让整体退出码变成 3。
静默跳过等于用户以为在盯着、其实没盯——那比不装哨兵更糟。
