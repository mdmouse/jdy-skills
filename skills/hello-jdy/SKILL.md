# 简道云连接诊断

用户装了简道云技能，但它不工作。这个技能回答**到底断在哪一环**。

一次跑完十项检查，每一项要么通过、要么给出这一条具体怎么修。全程只读：
只发一个查询授权应用列表的请求，不读业务数据，不写、不删。

## 怎么用

```
python3 scripts/probe.py
```

平台禁止出网、或用户只想看本地部分时加 `--no-network`。
要把报告发给别人：`python3 scripts/probe.py --save ~/简道云诊断.json`

把完整输出（含 JSON）呈现给用户，然后按下面解读。

## 先看结论行

| 结论 | 意思 | 跟用户怎么说 |
|---|---|---|
| `TRACK_SKILL` | 全通 | 一切正常，其它简道云技能可以放心用 |
| `TRACK_MCP` | 出网被这个平台的沙箱掐了 | 技能脚本在这个端用不了。换一个端，或改用官方「AI 连接」连接器查数（但写入仍然只能靠脚本） |
| `DEGRADED` | 有其它硬失败 | 按下面逐条对着修 |
| `INCOMPLETE` | 用了 `--no-network` | 去掉它重跑才有完整结论 |

## 十项检查，失败了各自怎么修

| 项 | 查什么 | 失败意味着 |
|---|---|---|
| C1 | 脚本能不能执行 | 这个平台跑不了 Python 脚本，简道云技能整套都用不了 |
| C2 | 能不能读技能包内的 `references/` | 能跑但读不到随包知识；换一个端，或改用把知识写在正文里的技能 |
| C3 | 能不能读 `~/.jdy/config.json` | 见下面「配置密钥」。也可能是文件不存在或权限不对 |
| C4 | 能不能读环境变量 `JDY_API_KEY` | C3、C4 **全失败**才是真问题：这个端拿不到本地密钥，只能在对话里粘贴 |
| C5 | 能不能写本地文件 | 导出类功能（Excel 导出、数据字典落盘、HTML 报告）在这个端不可用 |
| C6 | DNS 解析 | 网络不通，或沙箱掐了 DNS |
| C7 | HTTPS 出网 | 同上。企业网络的话先看代理设置 |
| C8 | 拿密钥真调一次简道云接口 | 密钥无效／过期／权限不够／IP 不在白名单。报告里有原始返回，照着看 |
| C9 | 状态目录落在哪 | 报告会写落点。若标了「本次会话有效」，设 `JDY_HOME` 钉死它，否则字段缓存和哨兵去重跨轮次会丢 |
| C10 | 装没装官方「AI 连接」 | 见下节 |

**C3/C4 全失败**是最常见的一类，多半是密钥根本没配。**C8 失败但 C7 通过**，
说明网络没问题、是密钥本身的问题。

## C10：这一端装没装官方连接器

| 结论 | 意思 | 怎么说 |
|---|---|---|
| 双轨 | 这一端的配置里有简道云 AI 连接条目 | 查数可以走官方连接器；**写入仍然只走技能脚本** |
| 技能单轨（市场有、本机未装） | 只在该端的连接器市场目录里见到 | 市场上有 ≠ 装了，别写成"已接入" |
| 技能单轨 | 读到了配置，里面没有简道云 | 这个端只有技能这一条路 |
| **未知** | 一个连接器配置文件都没探到 | **不许说成"没装"**——是没探到 |

两条边界，转述时别抹掉：

- **结论只属于当前这一端。** 本机别的端装了会另外提一句（`other_hosts`），
  那是那一端的结论，不能拿来说这一端。
- **配置里的 `enabled` 只是配置的说法**，不等于该端此刻真在用；
  读不到 `enabled` 的端（WorkBuddy 把它加密了）报未知，不替它猜。

## 密钥没配？当场配上

诊断报出 C3/C4 全失败，多半就是密钥根本没配。不要把用户丢回文档，用这个：

```
python3 scripts/setup.py
```

它会打印**建 Key 的四步**（逐字念给用户），以及配置文件该落在哪。
用户拿到 Key 之后：

```
echo '<把KEY粘在这里>' | python3 scripts/setup.py --stdin
```

它会**先调一次接口验证，通过了才落盘**——把一把用不了的 Key 写进配置，
只会让下一个报错更难查。写入时直接以 600 建文件。

已经配过、想确认还能不能用：`python3 scripts/setup.py --verify`

⚠️ **别让用户把 Key 发给你。** 让他自己粘进上面那条命令。
Key 也绝不要写成命令行参数——argv 会进 shell 历史，也会出现在 `ps` 里。

## 配置密钥（手动，可选）

没有密钥也能跑完 C1–C7，只是 C8 显示 SKIP——**要确认密钥本身有没有问题，
就得配上再跑一次。**

到简道云**开放平台 > 密钥管理 > 创建 API KEY** 建一把。
官方文档写着"企业版及以上"，但**试用账号实测可以调通**，验证阶段不必先付费。

任选其一，**两种都不要把密钥写进技能目录或仓库**：

```
export JDY_API_KEY="你的密钥"
```

或 `~/.jdy/config.json`（建完记得 `chmod 600`）：

```json
{ "api_key": "你的密钥" }
```

建议用**最小权限 Key**：限定应用 ＋ 只给用得到的接口 ＋ 开 IP 白名单。

## 安全边界

只发起 `POST /api/v5/app/list`（查询授权应用列表）这一个只读请求，
不读业务数据、不写入、不删除。报告中的密钥一律掩码为 `前4...后4`。

C10 会读连接器配置文件（宿主目录下的 `mcp.json` 一类），**纯只读，不改任何配置**。
认出宿主时只扫它自己那一份；认不出才扫全机，那时结论会写「未识别的宿主」。
这些文件里可能带 token，所以摘录走**白名单**：只输出 url / headers / disabled /
type / timeout，url 里的凭证与 header 值先掩码，其余字段一概不进报告。
