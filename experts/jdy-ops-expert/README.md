# 简道云运营助手（第三方） · jdy-ops-expert

by [aicliagent](https://aicliagent.com) · hi@aicliagent.com

> **非官方第三方项目。**「简道云」是帆软软件有限公司的注册商标，本专家包与帆软
> 无隶属、无合作、无授权、无认证关系，只调用其公开开放 API。出问题请找
> [aicliagent](https://aicliagent.com)，不要找简道云客服。

给天天在简道云里做表、导数、催审批的运营、行政、业务负责人用。用大白话说，
它去调简道云的 API 把活做完。

## 装了哪些技能

| 技能 | 一句话 | 写数据吗 |
|---|---|---|
| `hello-jdy` | 连接诊断：装了却用不了时告诉你断在哪一环，也负责引导配 Key | 只读 |
| `jdy-doc` | 数据字典与结构体检：把应用结构导成能交付的文件 | 只读 |
| `jdy-query` | 查数与即席报告：筛选、分组、聚合，出自包含 HTML 图表 | 只读 |
| `jdy-report` | 周报／月报：按周期拉数聚合、环比、趋势，推到群机器人 | 只读 |
| `jdy-excel-bridge` | Excel ⇄ 简道云：预检 → 分批幂等写入 → 回读比对 → 修复建议表 | ✍️ 写 |
| `jdy-clean` | 存量数据清洗：查重、规范化、批量打标；去重只标记不删除 | ✍️ 写 |
| `jdy-flow-ops` | 流程运营：待办收件箱、积压扫描、批量审批、按人催办 | ✍️ 写 |
| `jdy-org` | 通讯录与组织架构：姓名↔成员编号对照表、建部门、调归属 | ✍️ 写（不接任何删除接口） |
| `jdy-watch` | 数据哨兵：按规则定时巡检，命中就推群，自带去重不刷屏 | 只读 |

技能目录**不在本目录下**：它们由 `build_experts.py` 从仓库的 `skills/` 拷进
构建产物，避免仓库里存两份同名技能慢慢分叉。

## 和官方「简道云 AI 连接」的分工

**读走它，写走这里。** 官方连接器只能读；批量写入、审批动作、通讯录、附件、
跨应用同步、定时巡检、周期报表它一项都没有。

⚠️ 主 Agent 的系统提示词里写死了一条：**不许拿官方连接器的「单条新增记录」
工具套个循环当批量导入用**——它脏值静默存成 null 还返回成功，没有预检、
没有备份、没有回读。

## 需要什么

- Python 3.9+（各端沙箱自带）
- 一把简道云 API Key。没配的话让助手带你跑：

  ```
  python3 skills/hello-jdy/scripts/setup.py
  ```

  它先验证能不能调通，通过了才写进本机配置文件（权限 600）。
  **不要把 Key 贴在对话里。**
- 不需要 `pip install` 任何东西。

## 构建

在仓库根目录：

```
python3 build_experts.py --check
python3 build_experts.py
```

产物是 `dist/experts/jdy-ops-expert.zip`，**zip 的根就是包内容**
（第一层直接是 `.codebuddy-plugin/`、`agents/`、`avatars/`、`skills/`），
不套一层目录——套了开放平台会报「压缩包缺少 .codebuddy-plugin/plugin.json 文件」。
